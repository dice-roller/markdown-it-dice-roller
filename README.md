# markdown-it-dice-roller

A plugin for markdown-it to allow rolling of dice in Markdown documents

## Development playground

The Vite playground lets you edit Markdown, view the exact HTML generated by both plugins, and preview the result with interactive rollers.

Use Node.js `20.19+` or `22.12+` (the current Vite requirement), then run:

```sh
npm install
npm test
npm run playground
```

Open the local URL printed by Vite. To build the playground, run `npm run build:playground`.

Use `::: roll 1d6 :::` for a static roll result and `::: roller 1d20 :::` for an interactive roller. Click **Render preview** to process edits; dice are not rerolled just by typing.

The playground enables raw HTML to match the plugin's output, so use it only with trusted local Markdown. It is not safe for untrusted input.
